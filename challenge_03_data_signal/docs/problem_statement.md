# 问题陈述 — 挑战 03：数据 → 信号（Data → Signal）

## 业务背景

《杂货零售——数据驱动》系列的第三个里程碑，在挑战 01（结构）与挑战 02（诚信）打下的可信数据底座之上，回答一个更向前的问题：**干净的数据不只是正确，还必须具有启发性。**

本阶段的数据集覆盖 2018–2022 共 5 年，3 家门店（西雅图 / 波特兰 / 博伊西）、4 个产品品类（Beverages / Bakery / Meat / Produce）的**每日**销售（`sales_qty` 与 `sales_revenue`）。与挑战 02 相反，这份数据**干净、无注入错误**——其价值不在于「修补」，而在于「提取」。

## 需要回答的问题

1. **季节性**：销售存在哪些稳定的周期性模式？周度与年度节奏分别如何？哪些品类/门店更「季节敏感」？
2. **需求周期**：除了固定的周/年周期，还有哪些可自动发现的主导周期？
3. **外部因子**：节假日与价格如何影响需求？它们能否被量化并转化为预测信号？
4. **预测信号**：如何把原始交易转化为供策略与模拟使用的、可解释的预测？
5. **可信追溯**：每一张图表、每一个预测数字，如何追溯到可信数据与可复现步骤？

## 数据质量目标（区别于挑战 02）

这里不做清洗，而是做**信号工程与建模**。核心标准：

- **可解释**：模型结构能对应业务直觉（周循环、节假峰值、年度起伏）。
- **可复现**：任意一步都能一键重放；唯一的随机来源被显式固定（SARIMA 为确定性算法，无随机性）。
- **业务意识**：不是追求最低误差的「黑箱」，而是以「基准→SARIMA→SARIMAX」的阶梯证明每个建模选择的价值。
- **可追溯**：每个数字的来源（哪张表、哪个函数、哪次运行）都有据可查。

## 方法概览

| 阶段 | 方法 | 产出 |
|---|---|---|
| 信号探索 | 周期图（periodogram）、STL 分解、周/年画像 | 主导周期、季节强度 |
| 外部因子 | 美国联邦+零售节假日日历、`unit_price` 推导 | 节假日效应、价格弹性 |
| 无监督检测 | STL 残差 Z-score（|z|>3.5）→ 与日历交叉验证 | 异常/节假日自动识别 |
| 预测 | persistence / seasonal-naive 基准 → SARIMA(1,1,1)(1,0,1)[7] → SARIMAX(+节假日+年度傅里叶) | 全盲测一年（2022）的 MAE/RMSE/MAPE |

## 成功判据

- 主导周期（7 天周、~365 天年）由**无监督**方式自动发现。
- 每个预测都在明确基准之上，且改善方向与业务直觉一致（节假日因子应显著降低 Bae 类目等季节性尖峰）。
- 全流程端到端可复现，无人工干预。
